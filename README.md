1_sigint.c: Ctrl+C 입력 횟수를 세고, 세 번째 입력 시 종료 메시지를 출력합니다.
2_alarm.c: 지정한 시간 간격과 반복 횟수에 따라 알람을 실행합니다.

특히 2번 alarm 문제가 이해가 되지 않아 gpt에 문제 내용 설명과 수정 방안을 질문하였습니다.
